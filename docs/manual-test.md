# 実YouTubeでの手動確認（未実施）

このチェックリストは実際に聴きながら確認してください。自動テストはタブキャプチャのユーザー操作権限とYouTube配信音声の聴感を代替しません。

- [ ] 通常のYouTube動画を再生し、拡張を開くと動画タイトル・現在速度が表示される。
- [ ] キーを±1、±5、±12に変更する。テンポが変わらず音程が上下し、音が消えない。
- [ ] 音声処理中にポップアップを閉じても処理が続く。開き直すとキーが一致する。
- [ ] 速度を0.75倍にする。キーを維持したまま遅くなる。
- [ ] 指定秒数で巻き戻る。冒頭ではシーク可能な先頭に止まる。
- [ ] キー0とリセットで通常音声に戻る。リセットでは速度も1倍になる。
- [ ] 別タブのYouTubeからキーを変更すると、既存セッションを維持して案内する。
- [ ] タブを閉じる・再読み込みする・次の動画へ移動する。その後も再び操作できる。
- [ ] 一時停止・無音区間を経ても再生再開時に音が出る。
- [ ] YouTube自身で速度を変え、拡張を開き直すと現在値が表示される。
- [ ] ライブではシーク可能な範囲で巻き戻る。シーク不可なら案内される。
- [ ] Tab / Enter / Spaceで操作でき、フォーカスが見える。
