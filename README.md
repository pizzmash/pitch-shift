# PitchShift

YouTubeでカラオケ練習をするためのChrome拡張です。キーと再生速度を別々に調整し、練習したいフレーズを指定秒数だけ巻き戻せます。

<img src="docs/popup.png" alt="PitchShiftの操作パネル。キー・スピード・巻き戻しのボタンを配置" width="370">

## できること

| 操作 | 調整範囲 |
| --- | --- |
| キー変更 | −12〜＋12半音、1半音ずつ |
| 再生速度の変更 | 0.25〜2倍、0.05倍ずつ。音程を維持 |
| 巻き戻し | 1〜60秒。5・10・30秒のプリセット付き |
| リセット | キーを0、再生速度を1倍に戻す |

ボーカル除去・録音・音源のダウンロードには対応していません。

## インストール

必要なものは **Chrome 116以降**、ビルド用の **Node.js 20.6以降とnpm**、ソース取得用の **Git** です。Chromeにフォルダを読み込んで使います。

1. ターミナルでソースを取得し、ビルドします。

   ```sh
   git clone https://github.com/pizzmash/pitch-shift.git
   cd pitch-shift
   npm ci
   npm run build
   ```

2. Chromeのアドレスバーに `chrome://extensions` を入力します。
3. 右上の「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、生成された **dist** フォルダを選びます。リポジトリ全体ではなく、`manifest.json` が入っているフォルダを選択してください。
5. Chromeの拡張機能メニューからPitchShiftをツールバーに固定します。

## 使い方

1. YouTubeで練習したい動画を開き、再生します。
2. ツールバーのPitchShiftを開きます。
3. 「キー」の **＋／−** で歌いやすい音程に合わせます。プラスは高く、マイナスは低くなります。
4. テンポを落としたいときは「スピード」を変更します。例えば **0.75×** は通常の75%の速度です。
5. 同じフレーズを練習したいときは、秒数を選んで **「巻き戻す」** を押します。

パネルを閉じてもキー変更は続きます。「原曲に戻す」でキーのみ、「キーとスピードをリセット」で両方を元に戻せます。

キー変更は同時に1タブで使えます。別のタブへ切り替える前に、元のタブでキーを0に戻してください。巻き戻し秒数は次回も引き継がれます。

## 更新方法

ソースを取得したフォルダで実行します。

```sh
git pull --ff-only
npm ci
npm run build
```

その後、`chrome://extensions` にあるPitchShiftの **「↻」** を押し、YouTubeでパネルを開き直してください。`dist` を別の場所へコピーして読み込んだ場合は、先にコピー先を新しいビルドで置き換えてください。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 拡張を読み込めない | `npm run build` が成功しているか確認し、`dist` フォルダを選び直してください。 |
| ボタンが使えない | YouTubeの動画ページで開いてください。動画を再生してからパネルを開き直し、表示されたエラーも確認してください。 |
| 更新しても表示や動作が変わらない | Chromeが読み込んでいるフォルダを更新し、拡張管理画面の「↻」を押してください。 |
| 音が出なくなった | キーを0に戻すかリセットしてください。改善しなければYouTubeのページを再読み込みし、拡張も再読み込みしてください。 |
| 「別のタブでキーを変更中」と表示される | 元のタブで「原曲に戻す」を押すか、元のタブを閉じてください。 |
| 巻き戻せない | 再生開始を待ってから試してください。ライブなど、シークできない動画もあります。 |

解決しない場合は [Issues](https://github.com/pizzmash/pitch-shift/issues) に、Chromeのバージョン・操作手順・エラー文を記載してください。

## 音質とプライバシー

キー変更には短い遅延や音の揺れが生じる場合があります。特に大きくキーを変えると、歌声や楽器の音色も変わります。YouTubeタブ全体の音声を処理するため、広告の音声にも作用します。保護された動画では利用できない場合があります。

音声は端末内で処理し、録音・保存・外部送信はしません。拡張が保存する設定は巻き戻し秒数です。要求する権限は、選択したタブの動画操作・音声処理・設定保存に使います。

開発やテストを行う方は [開発ガイド](docs/development.md) を参照してください。
